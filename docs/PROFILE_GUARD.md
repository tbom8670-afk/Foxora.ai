# 🦊 ضد کانال و بیوگرافی (`modules/profile_guard`)

شناسایی **کانالِ متصل به پروفایل** کاربر (کارتِ «کانال» در صفحهٔ حساب) و
**جمله‌های فیلترشدهٔ بیوگرافی** — مستقیم از API سروش‌پلاس، نه از روی متن بیو.

## دستورها (فقط ادمین/مالک گروه)

| دستور | کار |
|---|---|
| `ضد کانال` یا `ضد کانال روشن` | روشن‌کردن قابلیت برای همین گروه |
| `ضد کانال خاموش` | خاموش‌کردن |

پیام‌ها: طبق قالب کارفرما —

```
⚠️ ضد کانال و بیوگرافی کاربران فعال شد
نام ها و جملات فیلتر شده « 67 »
```
```
▪️ضد فیلتر کانال و بیوگرافی روباه خاموش شد
```

## فهرست‌ها

| فایل | محتوا | مجازات |
|---|---|---|
| `config/profile_channel_names.txt` | نام کانال‌های ممنوع | حذف پیام + **سکوت دائمی** |
| `config/profile_bio_sentences.txt` | جمله‌های ممنوع بیو | حذف پیام + **سکوت ۴ ساعته** |

هر خط یک عبارت؛ خطِ `#` نادیده گرفته می‌شود. تغییر فایل **بدون
ری‌استارت** اعمال می‌شود (کش mtime؛ اگر هم نسخهٔ `config/` پروژه و هم
نسخهٔ runtime وجود داشته باشد، **تازه‌ترین** خوانده می‌شود).

پیش‌فرض‌های فعال (قابل حذف با `#`):

* نام کانال: `فیلم و سریال` ، `فیلم سوپر` ، `سوپر فیلم`
* جملهٔ بیو: `بیا تو کانال ما فیلم هست` ، `فیلم و سریال جدید در کانال ما` ،
  `برای دیدن فیلم به کانال ما بیا`

## قالب پیام حذف

نام کانال:

```
⛔ کاربر : @username
پیام شما پاک شد | دلیل : کانال فیلتر شده

↻- نام کانال بیوگرافی : فیلم و سریال   ← اسپویلر
↻- تعداد اعضا : 1245                    ← اسپویلر
↻- مجازات : سکوت دائمی                  ← عادی
```

جملهٔ بیو:

```
⛔ کاربر : @username
پیام شما پاک شد | دلیل : فیلتر بیوگرافی

↻- کلمه فیلتر بیوگرافی : بیا تو کانال ما فیلم هست   ← اسپویلر
↻- مجازات : 4 ساعت سکوت                             ← عادی
```

خطِ اول `Blockquote` + `Bold` است؛ دلیل و همهٔ مقدارها `Bold`.

جلوِ هر خط `↻-` است (نه `➖`) و مقادیرِ **نام کانال / تعداد اعضا /
جملهٔ فیلتر بیوگرافی** با entity `MessageEntitySpoiler` پنهان می‌شوند؛
فقط «مجازات» عادی و قابل‌دیدن است. برای تغییرِ این سلیقه فقط
`BOLD_*` و `SPOILER_VALUES` و `BULLET` در
`modules/profile_guard/texts.py` را عوض کنید.

## مسیر API

```
users.getFullUser#b60f5918
  └─ users.UserFull
       ├─ full_user : UserFull
       │    ├─ about                  → بیوگرافی
       │    ├─ personal_channel_id    → شناسهٔ کانالِ پروفایل
       │    └─ personal_channel_message
       └─ chats : Vector<Chat>        → همان کانال با title / participants_count / access_hash
```

اگر کانال در `chats` نبود: `get_input_entity(PeerChannel(id))` →
`channels.getChannels` → (فقط برای «تعداد اعضا») `channels.getFullChannel`.

## چرا ربات کند/خراب نمی‌شود

* **کش کوتاه**: هر کاربر یک اسنپ‌شات دارد با TTL (پیش‌فرض **۶۰ ثانیه**)،
  پس بیوگرافی عملاً همیشه تازه چک می‌شود ولی RPC هر کاربر به یک‌بار در
  دقیقه محدود می‌ماند.
* **کاربرِ سابقه‌دار همیشه «فورس» خوانده می‌شود**: هر کس یک‌بار سکوت
  گرفته (دائمی، یا موقتِ فعال/تازه‌تمام‌شده) در دفترچه می‌ماند و
  پیامِ بعدی‌اش بدون توجه به کش با پروفایلِ تازه بررسی می‌شود؛ بعد از هر
  مجازات هم کشِ همان کاربر دور ریخته می‌شود.
* همهٔ RPCها از یک سمافور + فاصلهٔ حداقلی (`0.35s`) + احترام به
  `FloodWaitError` رد می‌شوند؛ خطا ⇒ `retry_after` برای همان کاربر.
* فیلتر خالی ⇒ **صفر درخواست**.
* هر خطا در لاگ می‌ماند (`PROFILE GUARD ...`) و مسیر پیام را نمی‌شکند.

## ورودِ جمله‌ها از فایل (Termux)

فایلِ نمونه: `docs/profile_filters_template.txt`

**۱) خط فرمان (پیشنهادی، ساده‌ترین):**

```bash
# فایلی که سرخط CHANNEL / BIO دارد
python3 tools/profile_guard_import.py ~/filters.txt

# فایلی که سرخط ندارد: بخش را صریح بدهید
python3 tools/profile_guard_import.py ~/channels.txt --channel
python3 tools/profile_guard_import.py ~/bios.txt --bio

# فقط ببینید چه چیزی اضافه می‌شود (هیچ فایلی نوشته نمی‌شود)
python3 tools/profile_guard_import.py ~/filters.txt --dry-run
```

**۲) از داخل چت سروش (فقط مالکِ ربات):**

```
ضد کانال فایل /sdcard/filters.txt
ضد کانال فایل کانال /sdcard/channels.txt
ضد کانال فایل بیو /sdcard/bios.txt
```

قالب فایل (سرخط‌ها اجباری‌اند اگر از `--channel/--bio` استفاده نکنید):

```
CHANNEL
فیلم و سریال
فیلم سوپر

BIO
بیا تو کانال ما فیلم هست
```

* سرخط‌های پذیرفته‌شده: `CHANNEL` / `[channel]` / `کانال` — و
  `BIO` / `[bio]` / `بیو` / `بیوگرافی`.
* تکرارها نوشته نمی‌شوند (اجرای دوبارهٔ همان فایل بی‌خطر است).
* ربات فایل را **بدون ری‌استارت** می‌خواند (کش mtime).
* فایل بزرگ‌تر از ۲ مگابایت رد می‌شود و فایل ناموجود پیام روشن می‌دهد.

## تنظیم‌ها (اختیاری، `.env`)

| متغیر | پیش‌فرض | معنا |
|---|---|---|
| `PROFILE_GUARD_TTL` | `60` | عمر اسنپ‌شات پروفایل (ثانیه) |
| `PROFILE_GUARD_FRESH` | `120` | حداکثر عمرِ شاهد برای مجازات |
| `PROFILE_GUARD_BIO_MUTE` | `14400` | مدت سکوتِ تخلف بیو (۴ ساعت) |
| `PROFILE_GUARD_RPC_MIN_INTERVAL` | `0.35` | فاصلهٔ حداقلی RPCها |
| `PROFILE_GUARD_FETCH_TIMEOUT` | `12` | تایم‌اوت هر RPC |
| `PROFILE_GUARD_ERROR_RETRY` | `1800` | مکث پس از خطا برای همان کاربر |
| `PROFILE_GUARD_NOTICE_COOLDOWN` | `3600` | فاصلهٔ تکرارِ اخطارِ **همان تخلف** |
| `PROFILE_GUARD_REHEAL_INTERVAL` | `60` | فاصلهٔ تلاشِ دوبارهٔ سکوتِ دائمی |

## دوامِ مجازات پس از ری‌استارت

هر مجازات در `~/.{INSTANCE}/config/profile_guard_penalties.json` ثبت می‌شود
(فقط شناسه‌ها + نوع + زمان پایان؛ **هیچ متنی از بیو/کانال ذخیره نمی‌شود**).

* **هنگام بالا آمدن ربات**: `profile_guard.recover()` برای هر گروهِ روشن،
  سکوت‌های دائمیِ ثبت‌شده را در یک تسکِ پس‌زمینه دوباره اعمال می‌کند
  (پس ری‌استارت هیچ کاربرِ دائم‌ساکتی آزاد نمی‌شود).
* **وسط کار**: اگر کاربرِ دائم‌ساکت باز هم پیام داد (یعنی سکوتش از سمتِ
  سرویس برداشته شده)، همان لحظه پیامش پاک و سکوتش دوباره اعمال می‌شود؛
  بدونِ RPCِ پروفایل و بدونِ کارتِ تکراری، با فاصلهٔ حداقلی
  `PROFILE_GUARD_REHEAL_INTERVAL` تا اسپمِ درخواست نشود.
* سکوتِ موقتِ بیو بعد از پایانش به‌طور خودکار هرس می‌شود
  (`WATCH_GRACE = ۳۰ دقیقه` مهلتِ «زیرِ نظر» ماندن).

## ایمنی و «تشخیص اشتباه نکن»

* ادمین/مالک ثبت‌شده، VIP و خودِ ربات معاف‌اند.
* مجازات فقط با **شاهد تازه**؛ اگر اسنپ‌شات قدیمی باشد یک‌بار تازه می‌شود
  و اگر تازه‌سازی نشد، هیچ مجازاتی انجام نمی‌شود.
* کانال با نامِ نامعلوم (نبودِ `access_hash`) ⇒ هیچ تطبیقی انجام نمی‌شود.
* تطبیق **حرف حذف نمی‌کند**؛ فقط جداکننده‌ها (فاصله/نقطه/نیم‌فاصله/
  کشیده/اعراب/ایموجی) نادیده گرفته می‌شوند. بنابراین «فیلم» روی
  «فیلمبرداری» اثر نمی‌گذارد، ولی «ف ی ل م» و «ف.ی.ل.م» گرفته می‌شود.
