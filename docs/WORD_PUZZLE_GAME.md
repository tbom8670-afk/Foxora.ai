# 🧩 پازل کلمه — بازی کلمهٔ مخفی

بازی تک‌نفرهٔ ربات سوروش: **۲۰۰ مرحله**، هر مرحله یک **کلمهٔ مخفیِ فارسی** که
حروفش (به‌همراهِ چند حرفِ الکی) در یک جدولِ کوچک نشان داده می‌شود. جوابِ درست
= **۳ سکهٔ نقره** از همان اقتصادِ رسمیِ ربات.

## چطور بازی می‌شود

| کار | نتیجه |
|---|---|
| نوشتنِ `پازل کلمه` (یا `پازل کلمات` / `پازل`) | مرحلهٔ جاریِ همان کاربر باز می‌شود |
| جوابِ درست | «آفرین ✅ ۳ سکه نقره به موجودیت اضافه شد 🔖» + مرحلهٔ بعد، همان لحظه |
| جوابِ غلط | «❌ این کلمه درست نیست…» — تا پایانِ مهلت می‌شود دوباره تلاش کرد |
| پایانِ ۴۵ ثانیه | ربات کلمهٔ درست را می‌گوید و دور تمام می‌شود (بدونِ پاداش) |
| بعد از ۲۰۰ مرحله | پیامِ تبریک؛ دیگر مرحله‌ای باز نمی‌شود |

نمونهٔ صفحهٔ مرحله:

```
🧩 مرحله ۱ از ۲۰۰

ع - ش - ق
چ - س - پ
کلمه‌ی مخفی رو پیدا کن (۳ حرفی)

🎮 مهلت زمانی ۴۵ ثانیه
```

حروفِ جدول **Bold** هستند و با ` - ` از هم جدا می‌شوند (بازهٔ Bold از خودِ
ماژول می‌آید و در واحدِ UTF-16 حساب شده است؛ پس ایموجیِ سربرگ طول‌ها را جابه‌جا
نمی‌کند).

## قاعدهٔ ساختِ جدول

* **تعدادِ حروفِ الکی با مرحله بیشتر می‌شود:** مرحلهٔ ۱ تا ۱۰ ⇒ ۳ حرف، ۱۱ تا ۲۰
  ⇒ ۴، … هر ۱۰ مرحله یکی بیشتر تا سقفِ **۱۲** (از مرحلهٔ ۹۱ به بعد).
* **حرفِ الکی هیچ‌وقت از حروفِ خودِ کلمه نیست** (و بینِ خودشان هم تکراری نیستند).
* **۵ مرحلهٔ اول:** حروفِ کلمه به ترتیبِ درست در جدول می‌آیند (بعدشان حروفِ الکی).
  **از مرحلهٔ ۶:** همهٔ حروف (کلمه و الکی) قاطی می‌شوند.
* جدول برای هر مرحله **پایدار** است (تولیدِ تصادفی با بذرِ ثابتِ همان مرحله)، پس
  اگر کاربر دستور را دوباره بزند همان جدول را می‌بیند.
* تعدادِ ستون‌ها طوری انتخاب می‌شود که سطرِ آخر تک‌حرفی و بی‌ریخت نماند
  (۶ خانه ⇒ ۲ سطرِ ۳تایی — دقیقاً مثلِ نمونه؛ جدول‌های بزرگ‌تر ۳ تا ۵ ستون).

## قاعده‌های سخت

* **فقط صاحبِ بازی** جواب بدهد. مرحله به کلیدِ `(chat_id, user_id)` بسته است، پس
  پیامِ هر کاربرِ دیگر — درست یا غلط — **کاملاً نادیده** گرفته می‌شود.
* **پیشرفت هیچ‌وقت ریست نمی‌شود.** در `config/word_puzzle_progress.json` روی دیسک
  می‌ماند (به تفکیکِ گروه و کاربر). بعد از چند ساعت یا چند روز، همان کاربر از
  مرحلهٔ بعد ادامه می‌دهد: «مرحله ۴ از ۲۰۰».
* **هر مرحله فقط یک‌بار پاداش دارد.** مرجعِ تراکنش
  `word_puzzle:<chat_key>:<user_id>:<stage>` است؛ دفترِ اقتصاد آن را تکراری
  می‌بیند و دوباره پول نمی‌دهد. مرحله هم فقط جلو می‌رود.
* **کلمهٔ تکراری برای یک کاربر پیش نمی‌آید**، چون مرحله شمارندهٔ دائمیِ ۲۰۰
  کلمهٔ یکتاست.
* **نرمال‌سازیِ ورودی:** `ي`/`ك` عربی → `ی`/`ک`، `آ/أ/إ` → `ا`، `ۀ/ة` → `ه`، حذفِ
  اعراب، نیم‌فاصله و فاصله‌های اضافه.
* **دستورهای ربات جواب حساب نمی‌شوند:** اگر بازیکن وسطِ بازی `لیست بازی` یا
  `موجودی` بنویسد، دستورش اجرا می‌شود و پیامِ «غلط» نمی‌گیرد.
* **چند کاربر هم‌زمان** بازی می‌کنند و هیچ‌کدام روی دیگری اثر ندارد؛ تایمر و توکن
  هر مرحله جداست و تایمرِ کهنه با «توکنِ ناهم‌خوان» خودش را کنار می‌کشد.

## فایل‌ها

| مسیر | کار |

| `modules/word_puzzle/texts.py` | متن‌های فارسی + `TIME_LIMIT = 45` + Bold + ارقامِ فارسی |

| `tools/build_word_puzzle_words.py` | منبعِ یکتای کلمه‌ها + اعتبارسنجی + مرتب‌سازیِ ساده→سخت |

## بانکِ کلمه‌ها

۲۰۰ کلمهٔ **یکتا**، همه فارسی، رایج و کاملاً معنادار (عشق، دریا، کتاب، مهربان…)،
بدونِ نیم‌فاصله/فاصله/رقم — چون هر حرف باید یک خانهٔ جدول باشد:

| طول | ۳ | ۴ | ۵ | ۶ | ۷ | ۸ | ۹ |
|---|---|---|---|---|---|---|---|
| تعداد | ۳۰ | ۴۵ | ۴۵ | ۳۵ | ۲۵ | ۱۵ | ۵ |

### اضافه/اصلاحِ کلمه

```bash
python3 tools/build_word_puzzle_words.py
```

اسکریپت هر کلمهٔ تکراری، غیرِفارسی، یا کوتاه‌تر از ۳ حرف را رد می‌کند، طول‌ها را
حساب می‌کند و اگر استخرِ یک طول کم بیاید پیامِ فارسی می‌دهد و **چیزی نمی‌نویسد**.

## اقتصاد

* هر مرحله = **۳ سکهٔ نقره** (همان سیستمِ اقتصادِ موجود؛ کیفِ پولِ موازی ساخته
  نشده).
* پرداخت با `economy.award_game(chat_id, user_id, "word_puzzle", reference=…)`.
* اگر پرداخت همان لحظه خطا بدهد بازی قطع نمی‌شود: پیامِ «آفرین ✅ درست بود»
  می‌آید، خطا لاگ می‌شود و مرحله ثبت می‌شود تا کاربر گیر نکند.

## تست

```bash
PYTHONPATH=. python3 tests/test_word_puzzle.py
```

## یک نکته برای تصمیمِ نهایی

سربرگِ نمونهٔ کارفرما «🧩 مرحله ۱» بود، ولی در بخشِ ذخیرهٔ پیشرفت صریحاً خواسته
شده که وقتی کاربر برمی‌گردد پیامِ «مرحله ۴ از ۲۰۰» نشان داده شود؛ برای همین
سربرگ به شکلِ **«🧩 مرحله ۴ از ۲۰۰»** پیاده شد. اگر فقط «🧩 مرحله ۴» را می‌خواهی،
تغییرش یک خط در `modules/word_puzzle/texts.py` است (`HEADER_TEMPLATE`).
