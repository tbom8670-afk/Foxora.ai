# ===========================================================================
#  فهرست جمله‌های فیلترشدهٔ بیوگرافی (متن پروفایل کاربر)
# ===========================================================================
#  هر خط = یک جمله/عبارت. خطوط خالی و خطوطی که با # شروع می‌شوند
#  نادیده گرفته می‌شوند. تغییر فایل بدون ری‌استارت ربات اعمال می‌شود.
#
#  رفتار: تطبیق ⇒ حذف پیام + سکوت ۴ ساعته (نه دائمی) + قالبِ
#  «پیام شما پاک شد | دلیل : فیلتر بیوگرافی».
#
#  نکته‌ها:
#   * جمله‌ها با همان موتورِ ضدِ دور زدنِ نام کانال بررسی می‌شوند:
#     «بیا تو کانال» ، «بیاتوکانال» ، «ب.ی.ا تو کانال» و
#     «بیا  تو  كانال» همه گرفته می‌شوند.
#   * جملهٔ کوتاه‌تر از ۲ حرف پذیرفته نمی‌شود (جلوگیری از تطبیق تصادفی).
#   * هیچ حرفی از کلمات حذف نمی‌شود؛ پس کلمهٔ یک‌کلمه‌ای روی کلمهٔ
#     بلندتر اثر نمی‌گذارد.
#   * برای غیرفعال‌کردن یک خط، ابتدای آن # بگذارید.
# ===========================================================================
