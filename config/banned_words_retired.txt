# ⛔ کلمات ممنوعهٔ بازنشسته (Retired banned words)
#
# هر واژه‌ای که در این فایل باشد، از لیست کلمات ممنوعه حذف می‌شود —
# هم در نسخهٔ مخزن و هم در نسخهٔ runtime (``~/.foxora/config/
# banned_words.txt``). این فایل برای «حذفِ ماندگار» است، چون همگام‌سازی
# خودکار فقط واژه‌های تازه را به runtime اضافه می‌کند و چیزی را پاک
# نمی‌کرد؛ در نتیجه حذف یک واژه از مخزن روی نصب‌های موجود اثر نداشت.
#
# هر خط: یک واژه. خطوطی که با # شروع می‌شوند نادیده گرفته می‌شوند.
#
# «ک» (حرف تنهای فارسی) — عامل حذف پیام‌های سالم: هر پیام که این حرف
# به‌صورت جدا (بین ایموجی/علائم/فاصله) می‌آمد، «کلمهٔ ممنوعه» تشخیص
# داده می‌شد و پیام کاربر حذف/مجازات می‌شد. یک حرف هرگز «کلمه» نیست.
ک
