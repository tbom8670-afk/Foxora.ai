#  هر خط = یک نام کانال. خطوط خالی و خطوطی که با # شروع می‌شوند نادیده
#  گرفته می‌شوند. تغییر فایل بدون ری‌استارت ربات اعمال می‌شود (کش mtime).
#
#  نکته‌ها:
#   * تطبیق «دور زدن‌ناپذیر» است: فاصله، نیم‌فاصله، نقطه، خط تیره،
#     اعراب، کشیده و ایموجی داخل نام نادیده گرفته می‌شوند
#     («ف.ی.ل.م س.و.پ.ر» = «فیلم سوپر»).
#   * حروف عربی/فارسی یکدست می‌شوند (ي=ی ، ك=ک ، ة=ه ، أ/إ/آ=ا).
#   * عبارت یک‌کلمه‌ای فقط به‌صورت کلمهٔ مستقل تطبیق می‌خورد
#     («فیلم» روی «فیلمبرداری» اثر نمی‌گذارد).
#   * عبارت چندکلمه‌ای، حتی چسبیده («فیلموسریال») هم گرفته می‌شود.
#   * برای غیرفعال‌کردن یک خط، ابتدای آن # بگذارید.
# ===========================================================================
